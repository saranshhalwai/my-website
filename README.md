# Portfolio Website

Personal portfolio of Saransh Halwai, built with Next.js 16, React 19, TypeScript, and Tailwind CSS v4.

The previous UI has been removed in preparation for a redesign. The homepage is a blank starting point, and the root layout provides site metadata and minimal global styles. Existing public assets and social preview metadata remain available for the redesign.

## Development

Install dependencies with `bun install`, then start the development server with `bun run dev`.

Open [http://localhost:3000](http://localhost:3000) in your browser.

- `bun run build`: Build for production.
- `bun run start`: Start the production server.
- `bun run lint`: Run ESLint.
- `bunx tsc --noEmit`: Typecheck the project.
